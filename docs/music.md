# 松风入弦

《松风入弦》（Quiet Pavilion）是为「弈境 · 中国象棋」创作的原创背景音乐，随应用附带，可离线播放。

音乐采用 D、E、F♯、A、B 五声音阶，60 BPM、4/4 拍，共 20 小节。四段相互呼应的旋律以柔和拨弦为主，配以少量笛音和低音空五度，适合长时间下棋。没有人声和鼓点。

## 文件与再生成

- 音频：`public/music/quiet-pavilion.wav`
- 乐谱、音色合成与导出代码：`scripts/render-music.mjs`
- 在项目根目录执行 `node scripts/render-music.mjs`，无需安装额外依赖，也无需联网。

代码使用固定随机种子生成拨弦的轻微音色变化、气息噪声及量化抖动；在相同 Node.js 运行时中可逐字节重现音频。已连续生成两次并核对 SHA-256 一致。

拨弦通过带轻微非整数泛音的衰减弦振动合成，笛音通过正弦泛音、缓慢起音、收音与轻微颤音合成。混响由柔化的立体声延迟组成。单音均带平滑包络；结尾余音和混响按循环时间线延续到文件开头，背景持续音的周期与总时长对齐，以避免循环时出现突然截断或人为静音间隔。
