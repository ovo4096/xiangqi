# 水墨界面与验证

v1.4.0 将界面拆为模式选择、单人角色选择、对局三个阶段。双人模式直接进入同机棋盘；单人模式确认棋友后才进入对局。

## 视觉与交互

- 宣纸底色、手绘 SVG 远山、墨色字体与朱砂印章；保留真实木质 3D 棋盘。背景 SVG 为本项目编写，不依赖网络图片。
- 角色选择页展示大图、虚构人物简介、标志性对白和棋风。对局中仅展示当前棋友大图与对白。
- 对局保留行棋方、视角、悔棋、重开、认输、返回选局；声音开关和音量统一收进设置。移除棋谱、吃子统计、计时等常驻面板。
- 正上方俯视禁用 OrbitControls 的旋转、缩放及惯性，棋子拾取照常工作。立体视角按棋盘三维边界计算距离，并居中投影；再次点击「立体」重置视角。
- 棋盘在首次开局后复用。菜单页面隐藏棋盘、暂停动画帧及 NPC 计算，重新进入时恢复尺寸和棋局；最终卸载释放 GPU 资源。
- 背景音乐替换为《墨月闲庭》，选择、确认、返回及落子各有合成音效，音乐与语音独立控制。

## 回归范围

`npm test` 共 62 项：规则、四位 NPC、最强角色搜索、语音事件合并、媒体资源协议，以及不同窗口比例下完整棋盘的居中与边界计算。

`electron/smoke.cjs` 经实际 DOM、键盘及 Electron 鼠标事件验证：

- 启动先选模式、四位人物简介与图像、确认进入棋盘、离开和重开。
- 单人实际落子及回应；闻弈思考时悔棋、返回选局取消旧计算。
- 双人完整吃将流程，允许忽略威胁，只在实际吃将时结束；悔棋、重开确认及认输。
- 俯视前后拖动与滚轮操作的棋盘图像一致，返回立体后拖动确实改变画面。
- 快速交换只播放一条克制对白，静音时仍有字幕与中性表情。
- 本地音乐解码、96 秒循环、独立音量、语音压低音乐；按钮音效开关生效。
- 约 960 × 650、1280 × 720、1380 × 900 的内容区域，无页面滚动和关键控件裁切；高 DPI 取整允许 2 像素差异。
- WebGL 2 正常、渲染器无 Node.js、CSP 阻止外部请求和内联脚本。

自动验收使用 Electron 离屏渲染模式，窗口保持隐藏且音频静音，以避免隐藏原生窗口的截图合成不稳定。正常应用使用标准可见窗口渲染。JSON 报告及界面截图输出至 `YIJING_SMOKE_DIR`，CI 同时保留安装包与测试报告。
